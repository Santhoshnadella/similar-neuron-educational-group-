# FEED RANKING LOGIC

# Formula

```python
FeedScore =
(
EngagementWeight * EngagementScore
+
LearningValueWeight * EducationalQuality
+
RetentionWeight * RecallImprovement
+
CuriosityWeight * TopicNovelty
+
MasteryWeight * SkillProgression
)
-
AddictionPenalty
```
